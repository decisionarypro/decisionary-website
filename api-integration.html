What we agree before integrating

  • Which system is the source of truth for which data
  • Who is responsible for each side of the connection
  • How errors, retries and exceptions are handled
  • How data is validated after migration
  • What is handed over to operations

About Decisionary

Decisionary is a custom software development company in Seoul, South Korea. It works with businesses and digital agencies on web applications, platform rebuilds and API integrations. Scope and acceptance criteria are agreed in writing before the build, and the founder leads delivery.

FAQ

Can you integrate with a system that has no documentation?

Usually, after a technical review. We confirm what the system exposes before agreeing scope, so the estimate reflects it.

Do you take on integration-only projects?

Yes. Integration work with a definable scope is a good fit on its own.
