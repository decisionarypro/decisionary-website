  • สรุปข้อกำหนดจากการสัมภาษณ์ผู้เกี่ยวข้อง
  • รายการหน้าจอและฟีเจอร์ แยกเวอร์ชันแรกกับช่วงถัดไป
  • เกณฑ์การตรวจรับ: อะไรถือว่าเสร็จ
  • แผนเวลาและใบเสนอราคาที่ยืนยันแล้ว

ค่าใช้จ่ายจะแจ้งในการพูดคุย

สอบถามเรื่องการกำหนดขอบเขต ↗ (เปิดในหน้าต่างใหม่)

/05 วิธีการทำงาน

นี่คือสิ่งที่จะเกิดขึ้นหลังคุณติดต่อเรา

เราตอบกลับภายใน 1 วันทำการ จากนั้นดำเนินการตามลำดับ ได้แก่ ประเมิน กำหนดขอบเขต พัฒนา และตรวจรับ เปิดแต่ละขั้นตอนเพื่อดูว่าตกลงอะไรกันในขั้นนั้น

01ส่งบรีฟเป้าหมาย ผู้ใช้ งบประมาณ และกำหนดเวลา
บรีฟแรกที่มีประโยชน์สิ่งที่ต้องการสร้างหรือปรับปรุง ผลิตภัณฑ์และระบบที่มีอยู่ งบประมาณโดยประมาณและวันเปิดตัว และคุณเป็นลูกค้าโดยตรงหรือเอเจนซี
02ประเมินความเป็นไปได้การพึ่งพา ทางเลือกในการส่งมอบ และประเด็นที่ยังไม่ตัดสินใจ
ขอบเขตมาก่อนคำสัญญาตรวจสอบเป้าหมาย การเชื่อมต่อ ข้อจำกัด และกำลังคนก่อนยืนยันราคาหรือกำหนดเวลา
03ตกลงขอบเขตและทีมผู้เชี่ยวชาญ หมุดหมาย ส่วนที่ไม่รวม และเกณฑ์ตรวจรับ
เอกสารขอบเขตงาน (SOW)ยืนยันขอบเขต ทีมงานที่พร้อม ความเหมาะสมทางเทคนิค และเงื่อนไขเชิงพาณิชย์เป็นลายลักษณ์อักษร
04พัฒนาและตรวจทานติดตามความคืบหน้า คำขอเปลี่ยนแปลง และการทดสอบ
จุดตรวจทานผลงาน จุดตรวจทาน และคำขอเปลี่ยนแปลงเป็นไปตามที่ตกลงไว้ก่อนเริ่มงาน
05ตรวจรับและส่งมอบตรวจรับซอฟต์แวร์และส่งมอบสินทรัพย์ตามที่ตกลง
วางแผนการส่งมอบและตรวจรับเกณฑ์ตรวจรับและความรับผิดชอบในการส่งต่อตกลงกันก่อนเริ่มงาน

Decisionary ทำสัญญากับคุณโดยตรง และจัดทีมผู้เชี่ยวชาญที่เหมาะสมสำหรับแต่ละโปรเจกต์

/06 คำถามที่พบบ่อย

เรื่องที่มักกังวลก่อนจ้างงานภายนอก

โปรเจกต์ประเภทใดที่เหมาะสม?

เว็บแอปพลิเคชันสำหรับธุรกิจ การสร้างแพลตฟอร์มใหม่ และการเชื่อมต่อ API หรือข้อมูลที่กำหนดขอบเขตได้ เราตรวจสอบบรีฟก่อนเพื่อพิจารณาว่าสามารถยืนยันทีมและแผนการส่งมอบที่เหมาะสมได้หรือไม่

ถ้าข้อกำหนดเปลี่ยนระหว่างโปรเจกต์จะทำอย่างไร?

เราจะสรุปผลกระทบต่อกำหนดเวลาและค่าใช้จ่ายให้ก่อน และจะดำเนินการเมื่อคุณตกลงแล้วเท่านั้น ขอบเขตจะไม่เพิ่มหรือลดโดยที่คุณไม่ได้อนุมัติ

ทีมโปรเจกต์จัดตั้งอย่างไร?

เราจัดทีมตามขอบเขตของแต่ละโปรเจกต์ ประกอบด้วยผู้เชี่ยวชาญด้านพัฒนา PM ออกแบบ และ QA ที่เหมาะกับงาน ผู้ก่อตั้งเป็นผู้นำโปรเจกต์โดยตรง และรับผิดชอบการส่งมอบตามเกณฑ์การตรวจรับที่ตกลงกันก่อนเริ่มงาน

คิดราคาโปรเจกต์อย่างไร?

เราประเมินราคาหลังตรวจสอบผลงานที่ต้องส่งมอบ การพึ่งพา เกณฑ์การตรวจรับ และกำลังคน หากขอบเขตเหมาะสม สามารถทำสัญญาแบบราคาเหมา และชำระเงินตามหมุดหมายได้เช่นกัน

รับโปรเจกต์ขนาดเล็กไหม?

รับ สำหรับงานขนาดเล็ก เราข้ามขั้นตอนกำหนดขอบเขตแยกต่างหาก และส่งใบเสนอราคาหลังคุย 30 นาที

จ้างเฉพาะการกำหนดขอบเขตก่อนได้ไหม?

ได้ ภายใน 1–2 สัปดาห์ เราจะส่งมอบข้อกำหนด รายการหน้าจอและฟีเจอร์ เกณฑ์การตรวจรับ และใบเสนอราคาที่ยืนยันแล้ว หากจ้างพัฒนาต่อ ค่ากำหนดขอบเขตจะหักออกทั้งหมด หากไม่จ้าง คุณยังใช้เอกสารได้ตามเดิม

เป็นพันธมิตรด้านการพัฒนาให้เอเจนซีของเราได้หรือไม่?

ได้ เรายินดีหารือความร่วมมือแบบ white-label หรือที่เอเจนซีเป็นผู้นำ ความเป็นเจ้าของลูกค้า การรักษาความลับ ความรับผิดชอบ และขอบเขตการสื่อสารตกลงกันล่วงหน้า

รองรับโปรเจกต์ที่เกี่ยวกับเกาหลีและเอเชียตะวันออกหรือไม่?

เราตั้งอยู่ในเกาหลีใต้ และพิจารณาการประสานงานในพื้นที่ได้เมื่อความรู้ด้านตลาดและความต้องการพัฒนาซอฟต์แวร์สอดคล้องกัน ความเหมาะสมพิจารณาเป็นรายโปรเจกต์

Decisionary เป็นบริษัทแบบไหน

Decisionary เป็นบริษัทรับพัฒนาซอฟต์แวร์ในกรุงโซล ประเทศเกาหลีใต้ ทำงานร่วมกับธุรกิจและเอเจนซีดิจิทัลด้านเว็บแอปพลิเคชัน การสร้างแพลตฟอร์มใหม่ และการเชื่อมต่อ API ขอบเขตและเกณฑ์การตรวจรับจะตกลงเป็นลายลักษณ์อักษรก่อนเริ่มพัฒนา และผู้ก่อตั้งดูแลการส่งมอบด้วยตนเอง
