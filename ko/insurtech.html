보험 판매 플랫폼, 해 본 사람이 만듭니다

보험 상품에는 긴 입력 항목, 파트너마다 다른 규칙, 결제와 정산 절차가 함께 얽혀 있습니다. 보험사, 법인대리점(GA), 인슈어테크 팀을 위해 가입 흐름, 파트너 연동, 관리자 기능을 만들고, 개발 전에 범위와 검수 기준부터 합의합니다.

개발하는 것

  • 입력 단계와 항목을 줄인 온라인 가입·청약 흐름
  • API를 통한 판매 파트너·임베디드 보험 채널
  • 상품, 계약, 파트너 설정을 다루는 관리자 시스템
  • 가입 과정 전반의 결제·정산·예외 처리
  • 기존 기간계 시스템과의 데이터 이관·연동

보험 프로젝트가 흔히 틀어지는 지점

파트너마다 필요한 항목과 규칙이 다르고, 운영은 수작업 예외 처리에 기대고 있으며, 그 아래 상품 규칙이 정리되지 않은 채 고객 화면만 다시 그리게 됩니다. 그러면 범위가 계속 바뀝니다. 그래서 상품 규칙, 파트너 요구사항, 운영 예외를 먼저 정리한 뒤에 화면과 검수 기준을 합의합니다.

대표가 이끈 프로젝트

보험사, 판매 파트너, 최종 고객을 연결한 B2B2C 보험 판매 플랫폼(2018~2019). 대표는 제품 구조, 고객 가입 흐름, 관리자 요구사항, 파트너 연동을 맡았습니다.

  1. 01가입 전환율 12% → 28%
  2. 02평균 가입 시간 8분 → 3분
  3. 03파트너 API 채널로 신규 고객 약 1,200명 확보
  4. 04참여 기관 전반에 더 일관된 제품·운영 구조 정립

대표가 이전 직장·계약에서 이끈 프로젝트의 기록입니다. 고객사 이름은 공개하지 않습니다.

자주 묻는 질문

보험사와 일하나요, 인슈어테크 스타트업과 일하나요?

둘 다입니다. 보험사, 법인대리점, 인슈어테크 팀과 일하고, 고객사의 보험 상품을 만드는 디지털 에이전시와도 협업합니다.

기존 기간계 시스템과 연동할 수 있나요?

네. API나 데이터 인터페이스를 통해 연동합니다. 범위를 합의하기 전에 기간계 시스템이 제공하는 기능을 먼저 확인하고, 데이터 이관은 단계별로 계획합니다.

작은 범위부터 시작할 수 있나요?

네. 1~2주 범위 정의로 요구사항, 화면·기능 목록, 검수 기준, 확정 견적을 정리해 드립니다. 개발을 맡기시면 비용은 전액 차감됩니다.
