디시저너리 소개

디시저너리(Decisionary)는 서울에 있는 외주 개발사입니다. 기업과 디지털 에이전시의 웹 애플리케이션, 기존 서비스 재구축, API·시스템 연동을 맡습니다. 개발 전에 범위와 검수 기준을 문서로 합의하고, 대표가 납품까지 직접 이끕니다.

자주 묻는 질문

어떤 기술로 개발하나요?

요구사항과 기존 시스템을 검토한 뒤 기술 스택을 정하고, 업무범위기술서(SOW)에 명시합니다.

소스 코드는 누구 소유인가요?

코드와 문서의 소유권과 인계 방식은 개발 시작 전에 계약서에 정합니다.

출시 후 유지보수도 하나요?

운영 인계는 개발 전에 계획합니다. 출시 후 추가 작업은 별도로 합의합니다.
