홈/범위 점검

무료 점검 · 약 2분

외주 맡기기 전,
범위부터 점검하세요

질문 10개에 답하면 개발 도중 범위가 바뀔 위험과, 견적 전에 먼저 정할 일 3가지를 알려 드립니다.

가입 없이 바로 결과 · 이름·연락처는 묻지 않습니다

질문 10개 미리 보기

어떤 걸 묻나요

다섯 영역에 걸친 질문 10개입니다. 답마다 0점(정리됨), 1점(일부), 2점(정리 안 됨)으로 계산해 0~100점의 범위 위험도로 보여 드립니다. 낮을수록 좋습니다.

범위

  1. 만들 기능 목록이 문서로 정리돼 있나요?
  2. 첫 출시에 꼭 필요한 기능과 나중에 할 기능이 나뉘어 있나요?

검수

  1. 기능마다 "이렇게 되면 완료"라는 기준이 있나요?

연동·데이터

  1. 연동해야 할 외부 시스템은 몇 개인가요?
  2. 연동할 시스템의 API 문서와 테스트 환경이 있나요?
  3. 기존 서비스의 데이터를 옮겨야 하나요?

업무 규칙

  1. 결제·정산·권한 같은 예외 규칙이 정리돼 있나요?

결정·일정

  1. 요구사항을 최종 결정하는 사람은 누구인가요?
  2. 출시 날짜는 어떻게 정해졌나요?
  3. 예산 범위가 정해져 있나요?
