01 · 교육 · 2025–2026

대표가 이전 직장·계약에서 이끈 프로젝트

글로벌 학습 플랫폼 전환·데이터 이관

대표 역할: 제품 전략·프로그램 총괄

약 100개국 베타 출시 준비

개요

약 100개국 사용자를 대상으로 하는 다국적 학습 플랫폼 고도화 프로젝트입니다.

핵심 기능을 일관되게 유지하면서 조직 구조, 사용자 권한, 학습 배정, 보상 체계, 지역별 운영 요건을 모두 지원해야 했습니다.

기존 플랫폼의 사용자·학습 데이터를 새 환경으로 옮기는 작업도 포함되어, 현업 담당자·기술팀·운영 조직 사이의 조율이 필요했습니다.

과제

전 세계에 일관된 서비스를 제공하면서 조직별 규칙과 지역 운영 요건을 함께 맞춰야 했습니다.

여러 개발팀이 빠듯한 출시 일정 안에서 일했고, 데이터 이관·사용자 접근·시스템 검증·운영 준비가 프로젝트 곳곳에 의존 관계를 만들었습니다.

대표 기여

대표는 제품 전략과 프로젝트 리더 역할을 맡아 현업, 기획, 디자인, 개발, 인프라, 파트너 조직 사이의 요구사항과 주요 의사결정을 조율했습니다. 주요 업무는 다음과 같습니다.

  • 조직 단위 접근·권한 정책 설계
  • 학습 배정·보상·랭킹 관련 업무 규칙 정의
  • 시간대 관련 서비스 정책 조율
  • 사용자·조직·권한·학습 기록의 단계별 데이터 이관 원칙 수립
  • API 기반 이관과 일괄 이관의 책임 범위 정리
  • QA 계획, 출시 점검, 운영 인계 지원
  • 출시 필수 요구사항과 출시 후 개선 사항 분리

성과

프로젝트 기록 기준
  1. 01약 100개국 대상 2026년 4월 베타 출시 준비 지원
  2. 023단계 데이터 이관 전략 수립
  3. 03사용자 2만 명 규모 부하 테스트 검증 기준 정의
  4. 04출시 범위, 의존 관계, 검수 기준에 대한 합의 수준 향상

02 · 보험 · 2018–2019

대표가 이전 직장·계약에서 이끈 프로젝트

B2B2C 보험 판매 플랫폼

대표 역할: 제품 관리·연동 총괄

가입 전환율 12% → 28%

개요

보험사, 판매 파트너, 최종 고객을 연결하는 디지털 보험 판매 플랫폼입니다.

파트너 채널을 통한 보험 가입을 지원했으며, 고객용 화면, 관리자 기능, 결제 관련 업무, 외부 시스템 연동을 함께 다뤘습니다.

여러 참여 기관의 운영 요건을 지원하면서 보험 가입 과정을 간소화하는 것이 목표였습니다.

과제

보험 가입에는 고객 입력 항목이 많고, 파트너마다 요구사항이 달랐으며, 여러 운영 절차가 얽혀 있었습니다.

불편을 줄이려면 고객 화면을 다시 설계하는 것만으로는 부족했습니다. 상품 규칙, 파트너 연동, 관리자 기능, 결제·정산 흐름이 함께 맞물려 작동해야 했습니다.

대표 기여

대표는 플랫폼의 제품 구조, 고객 가입 흐름, 관리자 요구사항, 파트너 연동 조율을 맡았습니다. 주요 업무는 다음과 같습니다.

  • 고객 가입 흐름 재설계
  • 보험 상품·관리 기능 요구사항 정의
  • 고객용 기능과 관리자 기능 구조 설계
  • 보험사와 판매 파트너 간 요구사항 조율
  • 파트너 API 연동과 제품 흐름 정렬
  • 가입·결제·정산 과정의 운영 예외 처리 정리

성과

프로젝트 기록 기준
  1. 01가입 전환율 12%에서 28%로 향상
  2. 02평균 가입 시간 8분에서 3분으로 단축
  3. 03파트너 API 채널로 신규 고객 약 1,200명 확보
  4. 04참여 기관 전반에 더 일관된 제품·운영 구조 정립

03 · 모빌리티 · 2022

대표가 이전 직장·계약에서 이끈 프로젝트

모빌리티 앱 재구축

대표 역할: 제품·출시 총괄

66일 만에 출시

개요

사용자 경험 개선, 제품 단순화, 제한된 기간 안의 모바일 앱 출시에 초점을 둔 소비자용 모빌리티 앱 재구축 프로젝트입니다.

기존 기능을 모두 가져가는 대신 사용자 요구를 다시 살펴보고, 첫 출시에 담을 가치 높은 기능을 추려야 했습니다.

과제

기존 앱에는 기능이 많이 쌓여 있어 사용자와 개발팀 모두에게 복잡도가 컸습니다.

첫 출시 범위를 불필요하게 넓히지 않으면서 사용성 개선, 기술 품질, 개발 여력, 출시 일정을 함께 맞춰야 했습니다.

대표 기여

대표는 제품 범위 정의와 직군 간 개발 조율을 이끌었습니다. 주요 업무는 다음과 같습니다.

  • 사용자 인터뷰와 사용성 테스트 23회 진행
  • 후보 기능 36개를 고객 요구와 구현 우선순위 기준으로 검토
  • MVP 기능 15개 정의
  • 기획·디자인·개발 11명 팀 조율
  • 스프린트 우선순위, 개발 의존 관계, 출시 마일스톤 관리
  • 출시 전 품질 개선과 이슈 해결 지원

성과

프로젝트 기록 기준
  1. 01후보 기능 36개를 우선순위 MVP 기능 15개로 축소
  2. 0266일 만에 개선된 앱 출시
  3. 03당초 계획보다 약 27% 빠르게 출시 완료
  4. 04프로젝트 기록상 월간 활성 사용자 32% 증가
  5. 05앱 비정상 종료율 4.2%에서 0.8%로 감소

04 · 번역 서비스 · 2023

대표가 이전 직장·계약에서 이끈 프로젝트

번역 관리 SaaS·업무 디지털화

대표 역할: 프로덕트 매니저

관리 시간 약 40% 감소

개요

전문 번역 서비스의 프로젝트 조율과 운영 업무 효율을 높이기 위한 번역 관리 시스템입니다.

기존에는 번역 과정 전반에서 반복적인 수작업 조율, 진행 상황 확인, 참여자 간 연락에 의존했습니다.

이러한 운영 요구를 체계적인 소프트웨어 제품으로 바꾸는 데 집중했습니다.

과제

관리 부담을 줄이는 동시에 번역 프로젝트의 진행 상황과 납품 책임을 더 잘 보이게 해야 했습니다.

기능을 고르고 첫 출시 범위를 정하기 전에 실제 업무 방식을 이해하는 것이 중요했습니다.

대표 기여

대표는 사용자 인터뷰와 운영 프로세스 검토로 번역 전문가의 업무 흐름을 분석했습니다. 주요 업무는 다음과 같습니다.

  • 기존 운영 흐름 정리와 병목 파악
  • 사용자 요구와 역할별 시스템 요구사항 정의
  • MVP 기능과 개발 우선순위 구성
  • 요구사항을 사업 가치와 개발 난이도에 맞춰 조정
  • 프로젝트 일정, 이슈, 납품 위험 관리

성과

프로젝트 기록 기준
  1. 01번역 관리 시스템 도입 후 번역 프로젝트 관리 시간 약 40% 감소
  2. 02프로젝트 일정 준수율 95% 달성
  3. 03실제 운영 흐름에 기반한 MVP 우선순위 범위 확정

05 · 모바일 소비자 서비스 · 2023–2024

대표가 이전 직장·계약에서 이끈 프로젝트

모바일 플랫폼 개선

대표 역할: 제품·사업 총괄

월간 사용자 42% 증가

개요

이미 운영 중인 소비자용 모바일 플랫폼의 제품 개선 프로젝트입니다.

기존 사용자 여정의 불편 지점을 찾아 개선 우선순위를 정하고, 사용자 참여, 리텐션, 서비스 품질을 높이는 것이 목표였습니다.

대표 기여

대표는 데이터 분석, 사용자 의견, 제품 개발팀과 함께 개선 기회를 찾고 체계적인 출시 프로세스를 만들었습니다. 주요 업무는 다음과 같습니다.

  • Google Analytics와 Firebase로 가입·기능 사용 퍼널 분석
  • 우선 개선할 이탈 지점 3곳 도출
  • UI/UX 개선과 실험 우선순위 정의
  • A/B 테스트와 제품 백로그 의사결정 조율
  • 약 2~3주 주기의 정기 출시 운영

성과

프로젝트 기록 기준
  1. 01월간 활성 사용자 42% 증가
  2. 02사용자 리텐션 28%p 향상
  3. 03클릭률 18% 증가
  4. 04앱 스토어 평점 3.2에서 4.6으로 상승

06 · 공공·관광 · 2023–2024

대표가 이전 직장·계약에서 이끈 프로젝트

공공 관광 디지털 키오스크 플랫폼

대표 역할: 제품·프로젝트 총괄

기술평가 1위로 수주

개요

방문객이 화면을 직접 눌러 관광 정보를 찾는 디지털 키오스크 사업입니다.

공공 서비스 요건, 방문객 사용성, 소프트웨어 기능, 하드웨어 공급사 역량을 함께 맞춰야 했습니다.

과제

공공장소의 키오스크는 다양한 방문객이 쓸 수 있어야 했고, 동시에 조달 요건과 실제 설치 제약을 충족해야 했습니다.

방문객 여정을 명확히 정의하고 서비스 관계자와 외부 공급사를 조율하는 것이 성패를 좌우했습니다.

대표 기여

대표는 제품 전략, 사용자 경험 요구사항, 공급사 조율, 사업 제안 활동을 맡았습니다. 주요 업무는 다음과 같습니다.

  • 5개 사용자 그룹 인터뷰와 현장 관찰
  • 방문객 시나리오와 정보 탐색 요구사항 정의
  • 사용자용 기능과 화면 요구사항 구성
  • 하드웨어 공급사와 제품 요구사항 조율
  • 공공 사업 제안서 작성과 발표 주도

성과

프로젝트 기록 기준
  1. 015개 사용자 그룹을 바탕으로 사용자 경험 요구사항 정립
  2. 02외부 공급사와 기능·운영 요구사항 조율
  3. 03해당 조달 절차에서 기술평가 1위 달성
