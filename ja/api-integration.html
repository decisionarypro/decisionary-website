ホーム / API・システム連携

すでに使っているシステム同士をつなぐ

パートナーAPI、基幹システム、決済やデータの流れをつなぎます。連携は境界でつまずきます。責任が曖昧なとき、検証が抜けたとき、エラー処理の計画がないときです。そこを先に決めてから開発します。

つなぐもの

  • 組込型販売チャネルを含むパートナー・チャネルAPI
  • APIやデータインターフェースを介した既存の基幹・レガシーシステム
  • 決済、精算、通知の流れ
  • 旧プラットフォームと新プラットフォーム間のデータ移行
  • 複数の組織にまたがるシステム連携

連携前に合意すること

  • どのシステムがどのデータの基準になるか
  • 接続の各側を誰が担当するか
  • エラー、再試行、例外をどう扱うか
  • 移行後のデータをどう検証するか
  • 運用に何を引き継ぐか

Decisionaryについて

Decisionaryは、韓国・ソウルのソフトウェア受託開発会社です。企業とデジタルエージェンシー向けに、Webアプリケーション、既存システムの再構築、API連携を手がけます。開発前に範囲と検収基準を文書で合意し、代表が納品まで直接リードします。

よくある質問

仕様書のないシステムとも連携できますか？

多くの場合、技術確認の後に可能です。範囲を合意する前にシステムで何ができるかを確認し、見積に反映します。

連携作業だけを依頼できますか？

はい。範囲を定義できる連携作業であれば、単独でもお受けします。
