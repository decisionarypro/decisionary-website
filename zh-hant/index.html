/06 常見問題

委外之前最常擔心的問題

哪些類型的開發專案適合？

主要對象是業務用 Web 應用程式、既有平台重建，以及 API 與資料整合等可定義範圍的專案。我們會先審閱需求，再判斷能否確定合適的團隊與開發計畫。

專案進行中需求變了怎麼辦？

收到變更請求時，我們會先說明對時程與費用的影響，經您同意後再執行。未經您確認，範圍不會增加或減少。

專案團隊如何組成？

我們依專案範圍，組成由開發、PM、設計與 QA 專家構成的團隊。由創辦人直接主導，並依開工前議定的驗收標準負責交付。

專案報價如何決定？

在審閱產出物、相依關係、驗收要求與可投入人員後進行報價。範圍適合時可採總價合約，也可依里程碑分期付款。

小專案也接嗎？

接。規模較小的專案不需另做範圍定義，30 分鐘洽談後即可報價。

可以只先委託範圍定義嗎？

可以。我們會在一到兩週內整理需求、畫面與功能清單、驗收標準與確定報價。若繼續委託開發，範圍定義費用將從開發費中全額折抵；即使不委託，成果文件也可直接使用。

可以成為海外代理商的開發夥伴嗎？

可以。我們歡迎白牌或由代理商主導的合作，客戶關係、保密、執行責任與溝通方式皆事先協議。

可以支援韓國與東亞相關專案嗎？

我們位於韓國，當開發專案與當地市場需求相連結時可以討論合作。具體可行性依專案評估。

Decisionary 是一家什麼樣的公司？

Decisionary 是位於韓國首爾的軟體委外開發公司，為企業與數位代理商提供 Web 應用程式開發、既有平台重建以及 API 與系統整合服務。開發前以書面方式確認範圍與驗收標準，並由創辦人親自負責交付。
