/06 常见问题

外包之前最常担心的问题

哪些类型的开发项目适合？

主要面向业务 Web 应用、现有平台重构以及 API 和数据集成等范围可定义的项目。我们会先审阅需求，再判断能否确定合适的团队和开发计划。

项目进行中需求变了怎么办？

收到变更请求时，我们会先说明对进度和费用的影响，经您同意后再执行。未经您确认，范围不会增加或减少。

项目团队如何组建？

我们根据项目范围，组建由开发、PM、设计和 QA 专家构成的团队。由创始人直接主导，并按开工前约定的验收标准负责交付。

项目报价如何确定？

在审阅成果物、依赖关系、验收要求和可投入人员后进行报价。范围合适时可采用固定总价合同，也可按里程碑分期付款。

小项目也接吗？

接。规模较小的项目无需单独的范围定义，30 分钟沟通后即可报价。

可以只先委托范围定义吗？

可以。我们会在一到两周内整理需求、页面与功能清单、验收标准和确定报价。若继续委托开发，范围定义费用将从开发费中全额抵扣；即使不委托，成果文件也可直接使用。

可以成为海外代理机构的开发伙伴吗？

可以。我们欢迎白标或由代理机构主导的合作，客户关系、保密、执行责任和沟通方式均提前约定。

可以支持韩国和东亚相关项目吗？

我们位于韩国，当开发项目与当地市场需求相结合时可以探讨合作。具体可行性按项目评估。

Decisionary 是一家什么样的公司？

Decisionary 是位于韩国首尔的软件外包开发公司，为企业和数字代理机构提供 Web 应用开发、现有平台重建以及 API 与系统集成服务。开发前以书面形式确定范围和验收标准，并由创始人亲自负责交付。
